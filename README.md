# 🧠 What Is This?

**Antivirus Security Dashboard** is a modern web-based cybersecurity dashboard designed to bring security-oriented information, monitoring workflows, scanning interactions, and visual analytics into a centralized interface.

The project explores how a traditional security dashboard can be presented through a modern frontend experience with strong visual hierarchy and interactive components.
